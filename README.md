# HeaterWatch

Heater barge temperature worksheet — six tanks, average, text the office.

Live app: [heaterwatch.app](https://heaterwatch.app)  
Also: [heatwatch.grok.me](https://heatwatch.grok.me)

## What it does

- Six tanks (1P / 1S, 2P / 2S, 3P / 3S)
- Running average
- Saved readings over time
- Estimate time to target °F
- Send or copy a ticket to the office

Open `heat-ticket.html` on a phone. After the first load it works offline.

## Files

- `heat-ticket.html` — the app (HTML, CSS, and JS in one file)
- `tankerman-banner-v2.png` — header art
- `index.html` — opens the ticket
- `favicon.svg` — six-tank icon
