# Heatwatch

Heat Ticket — a single-file worksheet for heater barges.

Live app: [heatwatch.grok.me](https://heatwatch.grok.me)

## What it does

- Six tanks (1P / 1S, 2P / 2S, 3P / 3S)
- Running average
- Saved readings over time
- Estimate time to target °F
- Send or copy a ticket to the office

Open `heat-ticket.html` on a phone. After the first load it works offline. Use **Save to this phone** to keep a copy.

## Files

- `heat-ticket.html` — the app (HTML, CSS, and JS in one file)
- `index.html` — opens the ticket
- `favicon.svg` — barge icon
